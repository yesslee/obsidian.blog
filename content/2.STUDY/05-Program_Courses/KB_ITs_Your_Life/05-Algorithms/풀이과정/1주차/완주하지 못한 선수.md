#### 문제파악
#### 접근 방법
처음에는 단순히 ArrayList를 이용하여 배열을 ArrayList로 변환한 뒤, 완주자 ArrayList를 순회하여 참여자 명단에 완주자 이름이 포함되어 있으면 해당 참여자를 지워서 한 명만 남기는 방식으로 구현하였다.
→ 정확성 테스트는 통과하였으나 효율성 테스트는 실패

HashMap을 사용하여 처음 구현을 시도한 방식은 HashMap의 Key:Value를 String(참가자 이름)과 Boolean(완주여부)로 넣은 뒤 완주자 명단의 배열을 순회하며 일치하는 이름은 true로 체크하는 방식을 사용했었다.

완주여부를 Boolean으로 체크하다보니 동명이인 케이스를 해결할 수 없어서 이를 어떻게 해결해야할지 떠올리지 못한데서 시간을 많이 잡아먹었다.
#### 코드 구현
```java
// 효율성 테스트 실패(시간초과)
import java.util.ArrayList;
import java.util.List;
class Solution {
    public String solution(String[] participant, String[] completion) {
        String answer = "";
        ArrayList<String> p_list = new ArrayList(List.of(participant));
        ArrayList<String> c_list = new ArrayList(List.of(completion));

        for (String s : c_list) {
            if(p_list.contains(s)) p_list.remove(s);
        }
        
        answer = p_list.get(0); // 완주하지 못한 사람은 1명 = 완주자가 제거된 리스트의 첫번째 원소
        return answer;
    }
}
```

```java
import java.util.HashMap;
import java.util.Collection;
class Solution {
    public String solution(String[] participant, String[] completion) {
        String answer = "";
				HashMap<String, Integer> p_hash = new HashMap();
        
        for (String s : participant) {
            if (p_hash.containsKey(s)) p_hash.replace(s, p_hash.get(s) + 1);
            else p_hash.put(s, 1);
        }
        
        for (String s : completion) {
            if (p_hash.get(s) >= 1) {
                p_hash.replace(s, p_hash.get(s) - 1);
            }
        }
        
        for (String s : p_hash.keySet()) {
            if (p_hash.get(s) == 1) answer = s;
        }
        
        return answer;
    }
}
```
#### 배우게 된 점
> [!tip] 정렬을 이용한 방법도 있다!
> BUT... 정렬의 시간복잡도를 고려할 필요가 있다
> JAVA의 `Arrays.sort()` 의 평균 시간복잡도는 $O(nlog(n))$ 이지만 Worst Case는 $O(n^2)$
> > Worst Case: 두 배열이 서로 정반대로 나열되어 있는 경우(하나는 오름차순, 다른 하나는 내림차순)

```java
import java.util.Arrays;
class Solution {
    public String solution(String[] participant, String[] completion) {
        Arrays.sort(participant);
        Arrays.sort(completion);
        
        for (int i = 0; i < completion.length; i++) {
            if (!participant[i].equals(completion[i])) {
                return participant[i];
            }
        }
        return participant[participant.length - 1];
		}
}
```

- HashMap이 제공하는 함수 중 getOrDefault()의 존재를 알게되었다(몰랐어서 if 사용)
