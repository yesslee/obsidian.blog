#### 문제파악
#### 접근 방법
정렬하면 뭔가 될 것 같다는 생각을 하긴 했으나… 정렬이후 어떻게 처리해야할지까지는 생각하지 못했다…
#### 코드 구현
```java
import java.util.*;
class Solution {
    public boolean solution(String[] phone_book) {
        boolean answer = true;
        
        // 정렬 구현
        Arrays.sort(phone_book);
                
        for (int i = 0; i < phone_book.length - 1; i++) {
            if (phone_book[i + 1].startsWith(phone_book[i])) answer = false;
        }
        
        return answer;
    }
}
```

```java
import java.util.*;
class Solution {
    public boolean solution(String[] phone_book) {
        boolean answer = true;
        
        // 해시 구현
        Set<String> phone = new HashSet<String>();
        
        for (String s : phone_book) {
            phone.add(s);
        }
        
        for (String s : phone_book) {
            for (int i = 1; i < s.length(); i++) {
                String temp = s.substring(0, i);
                if (phone.contains(temp)) answer = false;
            }
        }
    }
}
```

#### 배우게 된 점
- 문자열을 오름차순 정렬하게 되면 시작부분이 같은 값들이 연달아 오게 된다!
