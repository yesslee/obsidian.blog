#### 문제파악
주어진 괄호 문자열의 첫번째 요소를 잘라서 맨 뒤에 붙여주는걸 반복하며 한 바퀴 도는 동안 유효한 괄호가 나오는 경우의 수를 구하는 문제
#### 접근 방법
기본적인 방식은 [[2.STUDY/05-Program_Courses/KB_ITs_Your_Life/05-Algorithms/풀이과정/2주차/Valid Parentheses|Valid Parentheses]] 문제 방식과 동일하게 접근하면 된다!

문자열을 차례로 하나씩 확인하면서 여는 괄호`( { [` 라면 스택에 집어넣고, 스택에 값이 존재할 때 닫는 괄호 `) } ]` 를 만난다면 스택에 가장 마지막으로 들어간 값이 해당 괄호의 짝이라면 스택에서 꺼내는 과정을 반복하며 문자열을 순회한 뒤, 스택이 비어있다면 유효한 괄호이므로 해당 갯수를 카운트하면 된다!
#### 코드 구현
```java
import java.util.*;
class Solution {
    public int solution(String s) {
        int answer = 0;
        String newStr = s;
        Deque<Character> stack = new ArrayDeque();
				// 처음에는 Stack 클래스로 구현했었으나, 오늘 수업 듣고 수정
        
        for (int i = 0; i < s.length(); i++) {
            stack.clear();
            for (int j = 0; j < newStr.length(); j++) {
                if (newStr.charAt(j) == '(' || newStr.charAt(j) == '{' || newStr.charAt(j) == '[') {
                    stack.push(newStr.charAt(j));
                } else if (!stack.isEmpty()) {
                    if (newStr.charAt(j) == ')' && stack.peek() == '(') {
                        stack.pop();
                    } else if (newStr.charAt(j) == '}' && stack.peek() == '{') {
                        stack.pop();
                    } else if (newStr.charAt(j) == ']' && stack.peek() == '[') {
                        stack.pop();
                    } else stack.push(newStr.charAt(j));
                } else {
                    stack.push(newStr.charAt(j));
                }
            }
            if (stack.isEmpty()) answer++;
            newStr = newStr.substring(1, newStr.length()) + newStr.charAt(0);
        }
        
        return answer;
    }
}
```

#### 배우게 된 점
substring으로 문자열 자르고 붙이는 과정 대신 같은 문자열을 한 번 더 붙여서 2배로 만들어두면 인덱스 넘어갈 걱정 없이 그냥 반복문 돌면 된다!!!!!

```java
import java.util.*;
class Solution {
    public int solution(String s) {
        int answer = 0;
        String newStr = s + s;
        for (int i = 0; i < s.length(); i++) {
		        if (isValid(newStr.substring(i, s.length() + i))) answer++;;
		    }
		    
		    return answer;
    }
    
    private boolean isValid(String s) {   
        Deque<Character> stack = new ArrayDeque();
       
        for (char current : s.toCharArray()) {
			      if (current == '(' || current == '{' || current == '[') {
					      stack.push(current);
					  } else {
							  if (stack.isEmpty()) return false;
							  
							  char target = stack.pop();
							  if ((target == '(' && current != ')') ||
									  (target == '{' && current != '}') ||
									  (target == '[' && current != ']')) {
											  return false;
							  }
					  }
	      }
        return stack.isEmpty();
    }
}
```

함수로 따로 빼서 구현 + 조건문 어떻게 넣느냐에 따라 코드 훨씬 깔끔해진다는걸 또 깨닫다…

`isValid` 함수 호출 할 때마다 $O(N)$
이 과정을 N번 하므로 N * N
→ 전체 시간복잡도는 $O(N^2)$

`substring()`은 시간복잡도에 큰 영향 주지 못함
