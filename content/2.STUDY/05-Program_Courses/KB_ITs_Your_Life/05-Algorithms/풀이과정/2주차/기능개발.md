#### 문제파악
각 기능의 개발속도는 모두 다르기 때문에 뒤에 있는 기능이 앞에 있는 기능보다 먼저 개발될 수 있고, 이때 뒤에 있는 기능은 **앞에 있는 기능이 배포될 때 함께 배포됩니다.**
#### 접근 방법
뒤에 있는 기능은 앞에 있는 기능보다 먼저 개발완료 될 수 있지만 배포는 앞에 있는 기능이 배포될 때 같이 배포!!
⇒ 선입선출(FIFO) = 큐를 이용하자!

처음 떠올린 로직?
- 큐에 progresses의 요소를 넣는다
- 큐가 빌 때까지 반복문을 돌며
    - 개발완료 됐는지 체크한다
    - 안 된 경우
        - 완성까지 필요한 일수를 체크하는 변수를 하나씩 늘리고 다시 반복문을 돈다
    - 완료된 경우
        - 완료된 요소를 큐에서 꺼낸다
        - 그 다음 요소도 완성된 상태인지 확인해서 완료상태면 같이 꺼낸다

⇒ 코드로 구현할 수 있을거라 생각했는데 구현 시 막히는 부분이 많았던걸 보면 조건을 잘못 줬던 것 같다…

```java
import java.util.*;
class Solution {
    public int[] solution(int[] progresses, int[] speeds) {
        List<Integer> answerList = new ArrayList();
        Queue<Integer> queue = new LinkedList();
        for (int i : progresses) queue.add(i); // progresses를 큐에 넣음(초기화)
        int idx = 0; // progresses & speeds index
        int cnt = 0; // 한 번에 배포되는 기능 수
        int needDay = 1; // 기능별 배포에 필요한 일자(며칠 걸리는지)
        int ing = 0;

        for (int i = 0; i < queue.size(); i++) {
            int beforeDay = 0;
            while (!queue.isEmpty()) { // 큐가 다 빌때까지 해당 작업 반복
                // 배포가능하다면
                if (queue.peek() + speeds[idx] * needDay >= 100) {

                    // System.out.println();
                    System.out.println(beforeDay + " " + needDay + " " + cnt);

                    cnt++; // 배포가능한 작업 수 증가시킴
                    queue.remove(); // 해당 작업을 큐에서 빼내고
                    idx++; // 인덱스 다음 progress 가리키도록함

                    if (cnt > 0 && beforeDay < needDay) {
                        answerList.add(cnt);
                        cnt = 0;
                        // break;
                    }

                    beforeDay = needDay;
                    needDay = 0; // 배포까지 필요한 일자 초기화

                    // System.out.println(needDay);
                    // System.out.println(cnt);
                } else { needDay++; }
            }
            // while 밖

				int[] answer = new int[answerList.size()];

    }
}
```

```java
// GPT에게 위의 코드 가지고 질문해서 수정된 코드
import java.util.*;
class Solution {
    public int[] solution(int[] progresses, int[] speeds) {
        List<Integer> answerList = new ArrayList<>();
        Queue<Integer> queue = new LinkedList<>();

        // 작업 완료까지 필요한 일수 계산하여 큐에 넣기
        for (int i = 0; i < progresses.length; i++) {
            int daysRequired = (int) Math.ceil((double) (100 - progresses[i]) / speeds[i]);
            queue.add(daysRequired);
        }
        // System.out.println(queue);

        while (!queue.isEmpty()) { // 작업 동시에 배포 확인하는 while
            int deployDay = queue.poll();  // 첫번째 작업 배포되는 날짜
            int count = 1;

            // 이후 작업이 동일한 배포 날짜에 배포 가능한지 확인하는 while
            while (!queue.isEmpty() && queue.peek() <= deployDay) {
                count++;
                queue.poll();
            }

            answerList.add(count);  // 결과 담는 answerList
        }

        // 일반 배열로 변환
        int[] answer = new int[answerList.size()];
        for (int i = 0; i < answer.length; i++) {
            answer[i] = answerList.get(i);
        }

        return answer;
    }
}
```
