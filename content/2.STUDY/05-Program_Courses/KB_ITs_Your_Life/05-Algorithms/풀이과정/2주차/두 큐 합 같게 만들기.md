#### 문제파악
#### 접근 방법
2주차 수업 교재의 [[큐 (Queue)#문제적용|큐 - 문제적용]] 참고하기

큐 2개 사용하여 각각의 큐의 합이 더 큰 쪽에서 작은 쪽으로 큐의 요소를 옮겨담으며 합이 같아질때까지의 횟수를 세면 된다.

또 다른 방법은 두 배열을 이어 붙여 원형큐처럼 만든 뒤, 각각 배열의 시작점을 포인터로 설정하여 포인터가 증가하는 방향으로 이동하는 횟수를 세는 것?
#### 코드 구현
```java
// 큐 2개로 구현
import java.util.*;
class Solution {
    public int solution(int[] queue1, int[] queue2) {
        int n = queue1.length;
        Queue<Integer> q1 = new ArrayDeque<>();
        Queue<Integer> q2 = new ArrayDeque<>();
        long q1Sum = 0;
        long q2Sum = 0;

        for (int value: queue1) {
            q1.add(value);
            q1Sum += value;
        }
        for (int value: queue2) {
            q2.add(value);
            q2Sum += value;
        }

        // 4n -> 큐에 원소 옯겨담는 과정에서 원래 큐 상태로 돌아올때까지 반복하는 최대 범위?
        for (int i = 0; i < 4 * n; i++) {
            if (q1Sum > q2Sum) {
                int value = q1.remove();
                q2.add(value);
                q1Sum -= value;
                q2Sum += value;
            } else if (q1Sum < q2Sum) {
                int value = q2.remove();
                q1.add(value);
                q1Sum += value;
                q2Sum -= value;
            } else { // q1Sum == q2Sum
                return i;
            }
        }
        
        return -1;
    }
}
```

```java
// 투포인터로 구현
public class Solution {
    public int solution(int[] queue1, int[] queue2) {
        int answer = -1;
        int[] queue = new int[queue1.length + queue2.length];
        System.arraycopy(queue1, 0, queue, 0, queue1.length);
        System.arraycopy(queue2, 0, queue, queue1.length, queue2.length);

        long q_sum = sum(queue1);

        double goal = (sum(queue1) + sum(queue2)) / 2.0;

        // 포인터 시작 위치 지정
        int i = 0;
        int j = queue1.length;

        for (answer = 0; answer < 3 * queue1.length; answer++) {
            if (i == j || j == queue.length) {
                return -1;
            }

            if (q_sum > goal) {
                q_sum -= queue[i];
                i++;
            } else if (q_sum < goal) {
                q_sum += queue[j];
                j++;
            } else {
                return answer;
            }
        }
        return -1;
    }
    
    private long sum(int[] queue) {
        long sum = 0;
        for (int i : queue) {
            sum += i;
        }
        return sum;
    }
}
```

#### 배우게 된 점
> [!question] Q. 어떻게 sum값이 큰 큐에서 작은 큐로 이동하는 횟수가 항상 최소 이동 횟수로 보장되는지?
> A. 반대의 경우 → sum값이 작은 큐에서 큰 큐로 이동하면 최소 이동 횟수 보장 불가

제한사항에도 다 이유가 있다
	각 요소의 최댓값 = $10^9$ = int 범위안에 들어오긴 함
	⇒ 합하면 int 범위 벗어남!(산술 overflow 가능성)

그래서 합한 값은 long type을 사용해줘야 함
