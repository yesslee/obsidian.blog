#### 접근 방법
prices를 순회하며 현재 인덱스가 가리키는 값이 스택의 peek에 들어있던 인덱스가 가리키는 값을 비교한다

현재 값이 크다면 answer의 해당 인덱스 자리에 현재 값과 peek 인덱스가 가리키는 값의 차이를 집어넣는다.

크지 않다면 현재 값의 인덱스를 스택에 추가한다.

이 과정을 prices 배열을 한 바퀴 돌 때까지 반복한다.

그 후 스택에 남아있는 값이 있다면 answer의 peek 인덱스에 기간을 계산하여 저장한다.

// 구현 시도 코드
import java.util.*;
class Solution {
    public int[] solution(int[] prices) {
        int[] answer = new int[prices.length];
        Deque<Integer> stack = new ArrayDeque<>();
        
        for (int current = 0; current < prices.length; current++) {
            if (!stack.isEmpty() && prices[stack.peek()] > prices[current]) {
                int before = stack.pop();
                // System.out.println(before);
                answer[current] = prices[before] - prices[current];
            } else if (!stack.isEmpty()) {
                // answer[current] = stack.pop();
            }
            stack.push(current);
        }

        System.out.println(stack);
        
        return answer;
    }
}

```java
import java.util.*;
class Solution {
    public int[] solution(int[] prices) {
        int[] answer = new int[prices.length];
        Deque<Integer> stack = new ArrayDeque<>();
        
        for (int current = 0; current < prices.length; current++) {
            while(!stack.isEmpty()) {
                int before = stack.peek();
                if (prices[before] > prices[current]) {
                    answer[before] = current - before;
                    stack.pop();
                } else break;
            }
            stack.push(current);
        }

        while(!stack.isEmpty()) {
            int idx = stack.pop();
            answer[idx] = prices.length - idx - 1;
        }
        
        return answer;
    }
}
```
