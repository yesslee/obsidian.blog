#### 코드 구현
```java
class Solution {
    int answer = 0;
    public int solution(int k, int[][] dungeons) {
        int n = dungeons.length;
        boolean[] visited = new boolean[n];
        backtrack(k, visited, n, dungeons, 0);
        
        return answer;
    }
        
    // 작성하다 만 코드
    void backtrack(List<Integer> current, int[] dungeon, boolean[] visited) {
        // base case
        if (current.size() == dungeons.length) {
            return;
        }

        // recursive call
        for (int i = 0; i < dungeon.length; i++) {
            if (visited[i]) continue; // 방문했던 건 건너뛴다

            current.add((Integer[]) dungeons[i]);
            visited[i] = true; // 방문했음을 표시
            backtrack(current, dungeons, visited);
            current.remove(current.size() - 1);
            visited[i] = false;
        }
    }
}
```

```java
class Solution {
    int answer = 0;
    public int solution(int k, int[][] dungeons) {
        int n = dungeons.length;
        boolean[] visited = new boolean[n];
        backtrack(k, visited, n, dungeons, 0);
        
        return answer;
    }

    void backtrack(int curr_k, boolean[] visited, int n, int[][] dungeons, int cnt) {
        // cnt update
        if (cnt > answer) {
            answer = cnt;
        }

        // recursive call
        for (int i = 0; i < n; i++) {
            if (curr_k >= dungeons[i][0] && !visited[i]) { // base case
                visited[i] = true;
                backtrack(curr_k - dungeons[i][1], visited, n, dungeons, cnt + 1);
                visited[i] = false;
            }
        }
    }
}
```

#### 배우게 된 점
answer 전역변수 설정
→ 매개변수로 넣으면 이전 값 반영 X

업데이트 필요한 요소 ⇒ 전역변수
함수 내에서만 사용하고 업데이트 필요 X ⇒ 매개변수

visited, n도 전역변수로 사용하면 매개변수 적게 쓸 수 있다
→ 매개변수에 매번 안 넣어도 동작하는 코드가 된다
