#### 문제파악
후보키란?
유일성과 최소성을 모두 만족하는 키

유일성: 릴레이션에 있는 모든 튜플에 대해 유일하게 식별되어야 하는 성질
→ 중복된 값이 존재하면 X

최소성: 릴레이션의 모든 튜플을 유일하게 식별하는 데 꼭 필요한 속성들로만 구성되어야 하는 성질
→ 최소한의 속성들로 유일하게 식별할 수 있어야 함
#### 접근 방법
각 컬럼에 대한 조합을 구하고, 각 조합의 컬럼에 해당하는 값들에 대해 중복 존재를 체크한다.
- 중복 값이 없는 속성(컬럼)이 있다면 후보키가 될 수 있으므로 카운트 + 1 한다
- 속성(컬럼) 하나만으로는 중복 값이 존재하지만 속성(컬럼) 2개 이상의 조합이 중복 값이 없다면 후보키가 될 수 있으므로 카운트 + 1 한다
⇒ 이 과정에서 후보키가 된 값은 복합키에 포함되면 최소성이 깨지므로 그 외의 것들만 후보키가 될 수 있는지 체크한다(백트래킹! ~~사실상 DFS 재귀~~)
#### 코드 구현
```java
import java.util.*;
class Solution {
    public int solution(String[][] relation) {        
        int colSize = relation[0].length;
        List<Set<Integer>> cand = new ArrayList<>();
        
        for (int size = 1; size <= colSize; size++) {
            List<Set<Integer>> combi = makeCombi(colSize, size);
            for (Set<Integer> c : combi) {
                if (isUnique(c, relation) && isMin(c, cand)) cand.add(c);
            }
        }
        
        return cand.size();
    }
    
    public boolean isUnique(Set<Integer> cols, String[][] relation) {
        int rowSize = relation.length;
        Set<String> rowSet = new HashSet<>();
        for (String[] row : relation) {
            StringBuilder rowStr = new StringBuilder();
            
            for (int col : cols) rowStr.append(row[col]);
            rowSet.add(rowStr.toString());            
        }
        if (rowSet.size() == rowSize) return true;
        return false;
    }
    
    public boolean isMin(Set<Integer> cand, List<Set<Integer>> candKeys) {
        for (Set<Integer> key : candKeys) {
            if (cand.containsAll(key)) return false;
        }
        return true;
    }
    
    public List<Set<Integer>> makeCombi(int n, int r) {
        List<Set<Integer>> combi = new ArrayList<>();
        dfs(new HashSet<>(), 0, n, r, combi);
        return combi;
    }
    
    public void dfs(Set<Integer> curr, int start, int n, int r, List<Set<Integer>> result) {
        // basecase
        if (curr.size() == r) {
            result.add(new HashSet<>(curr));
            return;
        }
        
        for (int i = start; i < n; i++) {
            curr.add(i);
            dfs(curr, i + 1, n, r, result);
            curr.remove(i);
        }
    }
}
```
