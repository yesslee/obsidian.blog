#### 문제파악
#### 접근 방법
맨해튼 거리가 2인 노드 = 현재 위치에서 상하좌우로만 2번 이동해서 갈 수 있는 노드
→ 맨해튼 거리 3인 노드는 확인할 필요 X

주어진 String의 문자 하나를 노드로 보고 BFS 실행
BFS 돌면서 맨해튼 거리가 3 이상이면 더 이상 실행X
방문 예정인 노드가 파티션이라면 방문 X
→ 다음 노드 조건 확인할 때 유효 범위인지, 방문 전인 노드인지 확인하되 파티션 아닌지도 같이 확인

맨해튼 거리 2 이하인데 P 만나면 거리두기 안 지켜지는 것이므로 false 반환
→ **단, 시작점이 P인 경우는 제외!**
#### 코드 구현
```java
import java.util.*;
class Solution {
    int[] dr = {1, 0, -1, 0};
    int[] dc = {0, 1, 0, -1};
    public int[] solution(String[][] places) {
        int n = places.length;
        int[] answer = new int[n];
        // rowLength = colLength = 5;
        
        for (int i = 0; i < n; i++) {
            if (check(places[i])) {
                answer[i] = 1;
            } else {
                answer[i] = 0;
            }
        }
        
        return answer;
    }
    
    public boolean bfs(int r, int c, String[] room) {
        // P 조건 해결하니 visited 선언부도 문제 있었다!
        // 의도대로 동작 안하던 코드에선 전역 static으로 선언되어 있었음
        // bfs 실행 시 각 대기실마다 초기화되고 방문 체크되어야 하는데 그러지 못해서 전부 1 출력되었던 것
        boolean[][] visited = new boolean[5][5];
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{r, c, 0});
        visited[r][c] = true;
        
        while (!queue.isEmpty()) {
            int[] curPos = queue.poll();
            int curRow = curPos[0];
            int curCol = curPos[1];
            int curDist = curPos[2];
            
            if (curDist >= 3) break; // 2까지는 방문, 3부터는 아예 예약 X
            
            // 수정 전 코드에서 테스트케이스 중 응시자 없는 경우만 통과되었던 이유
            // 시작 지점이 P일때 curDist가 0인 경우 -> P라서 바로 false 리턴해서 bfs 시작 못했던 것
            // 또한 r, c가 아닌 현재 좌표인 curRow와 curCol을 넣어줬어야 함
            if (room[curRow].charAt(curCol) == 'P' && curDist != 0) return false;
            
            for (int i = 0; i < 4; i++) {
                int nextRow = curRow + dr[i];
                int nextCol = curCol + dc[i];
                if ((0 <= nextRow && nextRow < 5) && (0 <= nextCol && nextCol < 5)) { // 유효범위 체크(그리드 안 벗어났는지)
                    // 방문한 적 있는지 && 파티션 아닌지 확인
                    if (!visited[nextRow][nextCol] && room[nextRow].charAt(nextCol) != 'X') {
                        visited[nextRow][nextCol] = true;
                        queue.offer(new int[]{nextRow, nextCol, curDist + 1});
                    }   
                }
            }
        }
        return true;
    }
    
    // 모든 사람이 거리두기 지키는지 확인하는 함수
    // 한 명이라도 거리두기 지키지 않으면 false
    public boolean check(String[] room) {
        for (int r = 0; r < 5; r++) {
            for (int c = 0; c < 5; c++) {
                if (room[r].charAt(c) == 'P') {
                    if (!bfs(r, c, room)) return false; // 거리 2이하에 P 있으면 true, 없으면 false 반환
                }
            }
        }
        return true;
    }
}
```

#### 배우게 된 점
문제에서 배열 등으로 여러번 확인? 필요한 경우에는 한 케이스에 대해서 구현하고 반복문으로 수행할 수 있게 수정하면 문제 접근 보다 쉽게 가능하다!
(places가 2차원 배열로 주어졌는데 그 중 하나에 대해서 bfs 구현한 뒤 places 반복문으로 확인하게 구현하면 조금 더 쉽게 접근 가능하다는 의미)

**🥲오늘의 교훈🥲**
- 전역변수 선언은 초기화 여부에 대해 잘 고민하고 선언하자
- 시작점에 대한 조건도 빼먹지 말자
