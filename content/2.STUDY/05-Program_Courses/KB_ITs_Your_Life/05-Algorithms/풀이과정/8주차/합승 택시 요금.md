#### 문제파악
A, B 두 사람이 출발점에서 출발해서 각가의 도착지점까지 택시를 타고 간다고 가정할 때, 최저 예상 택시요금을 return
(합승하지 않고 각자 이동하는 경우가 더 낮은 금액이라면 합승 X)
- n = node 갯수
- s = 출발점
- a = A의 도착점
- b = B의 도착점

`fares = [노드, 노드, 요금(각 node 사이의 예상 택시 요금)]` 형태의 배열이 들어있는 2차원 배열

주어진 그래프는 무방향 그래프
#### 접근 방법
어느 지점까지 합승으로 이동하는게 최소 금액이 나오는지 판단 필요
(각 노드마다 시작점으로 잡고 전부 다익스트라 돌려도 정답 나오긴 함 - 대신 효율성 실패)

**최적 합승 지점 찾기**
A 도착점에서 합승지점까지 가는 금액 + B 도착점에서 합승지점까지 가는 금액 + 시작점에서 합승지점까지 가는 금액
→ 최소인 값을 찾으면 최적 합승 지점!

⇒ **도착점을 시작점으로 취급해서 다익스트라 실행하는 발상의 전환!**

시작점, A 도착점, B 도착점 각 지점을 시작점으로 생각하고 각 노드까지 최소 비용을 구하고 비용을 누적해서 더한다

더한 값이 최소인 노드가 합승 최적 지점!!!

합승 안한 경우가 최적인 경우 = 각자 도착점 정반대인 경우 = 각자의 도착점(=다익스트라 시작점)이 최적으로 나온다?

#### 코드 구현
```java
import java.util.*;

class Edge implements Comparable<Edge> {
    int node, cost;
    
    public Edge(int node, int cost) {
        this.node = node;
        this.cost = cost;
    }
    
    @Override
    public int compareTo(Edge other) {
        return Integer.compare(this.cost, other.cost);
    }
    
    @Override
    public String toString() {
        return "Edge{" +
                "node=" + node +
                ", cost=" + cost +
                '}';
    }
}

class Solution {
    public int solution(int n, int s, int a, int b, int[][] fares) {
        int[] distance_sum = new int[n + 1];
        Map<Integer, List<Edge>> graph = new HashMap<>();
        for (int i = 1; i <= n; i++) {
            graph.put(i, new ArrayList<>());
        }

        for (int[] fare : fares) {
            graph.get(fare[0]).add(new Edge(fare[1], fare[2]));
            graph.get(fare[1]).add(new Edge(fare[0], fare[2]));
        }
        
        int[] startDist = dijkstra(graph, s, n, n);
        int[] aDist = dijkstra(graph, a, n, n);
        int[] bDist = dijkstra(graph, b, n, n);
        
        for (int i = 0; i < distance_sum.length; i++) {
            distance_sum[i] += startDist[i];
            distance_sum[i] += aDist[i];
            distance_sum[i] += bDist[i];
            // distance_sum[i] = startDist[i] + aDist[i] + bDist[i];
            // 덧셈 이 방식이 더 나은가...?
        }
        
        int min = Integer.MAX_VALUE;
        
        for (int i : distance_sum) {
            if (i < min) {
                min = i;
            }
        }
        
        return min;
    }
    
    public int[] dijkstra(Map<Integer, List<Edge>> graph, int start, int end, int n) {
        int INF = Integer.MAX_VALUE;
        int[] distance = new int[n + 1];
        Arrays.fill(distance, INF);

        Queue<Edge> pq = new PriorityQueue<>();
        pq.add(new Edge(start, 0));
        distance[start] = 0;
        
        while (!pq.isEmpty()) {
            Edge current = pq.remove();
            if (distance[current.node] < current.cost) continue;
            
            for (Edge next : graph.get(current.node)) {
                int nextCost = distance[current.node] + next.cost;
                if (nextCost < distance[next.node]) {
                    pq.add(new Edge(next.node, nextCost));
                    distance[next.node] = nextCost;
                }
            }
        }
        
        return distance;
    }
}
```
