**그래프, BFS, DFS 복습**

DFS, BFS 특성 = 시작점과 연결된 모든 노드 1번씩 방문(순회)

인접행렬보다 인접리스트 많이 보게될 예정(인접리스트로 만들어서 쓰는게 더 편하기도 함)

인접행렬에서 연결여부 확인 → `graph[i][j] = 1` 인걸 확인

인접리스트는 해당 리스트에 들어있는 게 연결된 노드들!

BFS

가까운 곳 부터 방문하는 특성 = 특정 노드까지 도착하는데 최소로 이동

→ 최단거리 알아내는 문제 등에 적용(거리두기 문제도 최단거리 응용!!)

큐를 사용해서 방문 예정인 노드를 예약 후 하나씩 꺼내서 방문한 뒤 그 다음 방문예정인 노드 예약(→ 반복)

```
bfs() {
	큐 선언 및 생성
	큐에 첫번째 노드 방문 예약(큐에 넣기)
	visited 첫번째 값 방문표시
	
	큐가 빌 때까지
		큐에 예약된 노드 하나 꺼내서 방문
		현재 방문한 노드 기준으로 그래프 돌면서
			다음에 방문 예정인 노드가 visited로 방문표시 안되어 있으면
				큐에 다음 노드 방문 예약
				visited로 다음 노드 방문표시
}
```

BFS 시간복잡도

시간복잡도 = 실행시간 = 코드 실행횟수와 연관

O(vertex(노드)의 갯수만큼 실행 + edge(간선)의 개수만큼 실행) = $O(V + E)$

인접 행렬의 경우는 $O(V + E^2)$

BFS,DFS에서 시간복잡도 고려하는 문제는 별로 안 나옴(대부분 BFS, DFS로 풀 수 있는지 확인하는게 문제 의도)

DFS

```
dfs() {
	visited에 현재 노드 방문표시
	현재 노드 기준으로 그래프 돌면서
		다음에 방문 예정인 노드가 visited로 방문표시 안되어 있으면
			다음노드 dfs 실행
}
```

BFS로만 풀 수 있는 문제 = 최단거리 문제

- 단어 변환
- 코인체인지
- 블록이동하기(챌린지)
- 미로탈출
- 게임맵 최단거리

DFS로 풀었을 때 더 효율적으로 풀리는 문제 → 트리 문제?

(이전의 타겟 넘버)
