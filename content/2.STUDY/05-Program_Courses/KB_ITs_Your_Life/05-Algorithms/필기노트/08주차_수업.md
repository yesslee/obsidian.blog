# 우선순위 큐

큐 = 선입선출(FIFO)

→ 기준 = 시간, 먼저 들어온 순서 등

우선순위 큐

→ 기준 = **우선순위!**

들어운 순서에 따라 먼저 나가는게 아닌 정해진 우선순위 기준에 따라서 높은 우선순위를 갖는 것이 먼저 나간다

7, 4, 6, 1을 차례로 우선순위 큐에 넣었을 때

숫자가 클수록 높은 우선순위를 갖는다고 한다면 7 → 6 → 4 → 1 순서로 나간다

일반적인 큐라면 7 → 4 → 6 → 1 순서

Heap 자료구조를 구현한게 완전 이진 트리

완전 이진 트리 범위 안에 heap이 존재

우선순위 큐 구현 위해서 다양한 자료구조 사용 가능

→ List, LinkedList는 시간복잡도 측면에서 비효율적. Heap으로 구현 시 효율적인 구현이 가능

리스트로 구현한다면 deque과정이 O(n)의 시간복잡도를 가짐

enqueue시마다 정렬해두는 방식으로 구현한다면 O(nlogn)의 시간복잡도

→ 시간이 오래걸린다…

완전이진트리로 구현한다면?

이진 트리

- 가질 수 있는 자식 노드의 개수가 최대 2인 트리

완전 이진 트리

- 이진트리이면서 자식 노드는 Left → Right 순서로 채워져야하는 트리

enqueue와 dequeue과정 합리적으로 변화

트리 구조에 삽입 → 부모노드와 자식노드간의 우선순위 비교해서 가장 높은 우선순위를 갖는 노드를 root에 저장

root 노드 꺼낸 뒤 가장 마지막 노드를 root에 넣어서 우선순위 비교하여 가장 높은 우선순위를 갖는 노드가 root에 위치하도록 재배치

시간복잡도 O(logn) = 거의 1에 가까운 시간 복잡도 = 리스트 구현보다 훨씬 효율적

자바에서는 직접 우선순위큐를 구현하는게 아닌 이미 내장된 자료구조 가져다가 사용 = 사용법만 알고 있으면 풀 수 있다

하지만 개념과 동작원리 알고 있다면 다양하게 접목 가능

## Heap

완전 이진 트리 형태의 자료구조

min heap: 부모 노드의 값이 자식노드의 값 보다 작은 트리 형태

max heap: 부모 노드의 값이 자식 노드의 값보다 큰 트리 형태

형제 노드간의 크기는 상관 X

```java
Queue<Integer> pq = new PriorityQueue<Integer>();

// enqueue
pq.add(3);
pq.add(1);
pq.add(8);

// dequeue
while (!pq.isEmpty()) {
		Integer value = pq.remove();
		System.out.println(value);
}
```

결과는 1 → 3 → 8

기본 = 숫자 작을수록 우선순위 높다고 판단 = min heap

max heap은 어떻게 구현?

인스턴스 생성 시 `Collections.reverseOrder()` 추가하면 max heap 생성 가능

우선순위를 커스텀하고 싶을 때는?

이름과 나이 같이 들어있는 데이터에 대해 우선순위 비교

heap의 시간복잡도

|작업|시간복잡도|
|---|---|
|힙 생성|$O(n)$|
|push|$O(\log n)$|
|pop|$O(\log n)$|

⇒ 반복적으로 최대값 혹은 최솟값을 찾아야 하는 경우 활용 가능한 자료구조

반복적으로 최대값 혹은 최솟값을 찾아야 하는 경우 매번 새로 정렬하는 건 비효율적. 우선순위 큐를 활용하면 효율적으로 해결 가능!

매번 새로 정렬 → O(n^2logn)

# 다익스트라 알고리즘(Dijkstra Algorithm)

다익스트라 알고리즘 구현 시 우선순위 큐 사용

(BFS에서는 큐 사용!)

가중치 그래프에서 사용되는 최단거리(Shortest Path) 찾는 알고리즘

가중치 없다면 BFS로 최단거리 찾을 수 있다!

가중치가 있다면?

완전탐색으로 모든 경로에 대해 탐색해 본 뒤 가장 짧은 경우를 찾는다 → 가능하긴 하지만 비효율적

이를 보다 효과적으로 수행하는 알고리즘이 다익스트라 알고리즘

다익스트라 알고리즘 = **가중치 그래프**에서 시작점과 도착점이 주어졌을 때 **최단 경로**를 return하는 알고리즘

구현 방법

현재 위치에서 방문 가능한 노드 중 가장 비용이 낮은 곳 방문(비용이 가장 낮은 곳 = 우선순위 기준)

```
1. 우선순위 큐에 시작 노드 추가
while () {
   2. 우선순위가 가장 높은 노드 추출 (= 현재 노드 방문)
   3. 방문 여부 확인
      4. 비용 업데이트 (비용 누적, 누적된 비용은 최소 비용?)
      5. 현재 노드와 연결된 노드 우선순위 큐에 추가(비용 낮은걸 우선순위 기준으로 큐에 추가)
}
4. 목적지에 기록된 비용 반환
```

다익스트라에서도 노드 번호와 누적된 비용(총 거리) 큐에 같이 저장
