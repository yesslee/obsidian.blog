# 네트워크 운용기기
## RAID
> [!info] RAID 란?
> 여러 개의 물리적인 저장 장치를 마치 하나의 저장 장치처럼 사용하도록 구성하는 기술
> 
> 장점
> - 운용 가용성, 데이터 안정성 증대
> - 디스크 용량 증설의 용이성
> - 디스크 I/O 성능 향상

### RAID 0 (스트라이핑)
![[RAID 0.png]]
- 구성 방식: 데이터를 블록 단위로 나누어 각 디스크에 분산 저장
- 최소 디스크 수: 2개
- 특징: 데이터 분산 저장 X (Parity 없음)
- 장점: 빠른 읽기/쓰기 가능
- 단점: 장애 복구 불가
	→ 디스크 하나만 고장나도 전체 데이터 손실

### RAID 1 (미러링)
![[RAID 1.png]]
- 구성 방식: 동일한 데이터를 2개의 디스크에 동일하게 저장
- 최소 디스크 수: 2개
- 특징: 데이터 복제
- 장점: 높은 데이터 안정성, 복구 용이
- 단점: 저장 효율 낮음, 비용 증가
### RAID 5 (스트라이핑 + 패리티)
![[RAID 5.png]]
- 구성 방식: 데이터와 패리티를 블록 단위로 분산 저장
- 최소 디스크 수: 3개
- 특징: 패리티 분산 저장으로 복구 가능
- 장점: 저장 공간 효율 좋음, 장애 복구 가능
- 단점: 복구 시 느림, 성능 저하 가능
### RAID 6 (RAID 5 + 이중 패리티)
![[RAID 6.png]]
- 구성 방식: 2개의 패리티를 사용해 더 높은 안정성 확보
- 최소 디스크 수: 4개
- 특징: 디스크 2개까지 장애 허용
- 장점: 매우 높은 안정성, 대규모 환경 적합
- 단점: 저장 효율 낮음, 쓰기 성능 저하

> [!info] Parity 란?
> 데이터를 복구할 수 있도록 하는 오류 검출용 중복 정보
> RAID 5, RAID 6에서 사용

## 네트워크 장비
- 물리 계층: Repeater(신호의 재생 및 증폭), HUB
- 데이터 링크 계층: Bridge
- 네트워크 계층: Router (가장 많은 계층 지원)
- 전송 계층: Gateway (다른 통신망과 상호 접속)

## 네트워크 용어
### VLAN(Virtual LAN)
물리적인 하나의 LAN을 논리적으로 여러 개로 나누어 네트워크 관리

### NAT(Network Address Translation)
내부 망 → 사설 IP 주소 사용하여 통신
외부 망 → NAT를 거쳐 공인 IP 주소로 자동 변환

네트워크 주소 변환(NAT)은 IP 패킷의 TCP/UDP 포트 숫자와 소스 및 목적지의 IP 주소 등을 재기록하면서 라우터를 통해 네트워크 트래픽을 주고받는 기술

패킷에 변화가 생기기 때문에 IP나 TCP/UDP의 Check sum도 다시 계산되어 재기록해야함
