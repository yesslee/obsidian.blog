옛날옛적... SW 중심대학 사업에 선정되어 신입생들에게 Lenovo Thinkpad를 하나씩 나눠줬던 나의 학교

코딩의 c도 모르는 채 입학해서 받은 노트북의 기본 OS는 Linux Ubuntu였다

동기들은 과에 항상 있는 컴잘알+윈도우설치 가능한 USB 가진 친구에게 부탁해서 파티션 나눈 뒤 듀얼부팅으로 윈도우 깔아서 쓰기도 했지만 파티션 나누면 저장공간 줄어드는게 싫어서 리눅스 ONLY 노트북으로만 사용했었다

여튼 꽁으로 받았던 노트북은 졸업학년 때 맥북을 구매한 뒤 쳐다보지도 않고 있었는데, 리눅스 마스터 1급 자격증 시험을 준비하려니 실기 실습환경으로 쓰기에 딱 좋다고 생각해서 간만에 다시 꺼냈다.

... 노트북 배터리가 부풀어 있어서 일단 제거하고 배터리부터 구매하려고 했더니 국내 판매가는 ~~싸가지없는금액~~ 생각보다 높길래 알리로 눈을 돌렸다. 여튼 알리에서 잘 골라서 주문하고, 전원 꽂아둔 채 켰더니 잘 켜졌다.

그리고 시스템 정보를 확인하니 22.04 LTS 버전이었다. 우분투는 24년 4월부터 24.04 LTS를 출시했으니 최신 LTS 버전이 나온지도 벌써 1년이 지난 상태... 업그레이드를 하기로 결심했다.

참고한 블로그들


거의 4년간 방치되어있었기 때문인지 dist-upgrade 명령어를 입력했더니 한참을 걸려서 패키지 설치/제거가 진행되더라...

(이미지)

대충 읽고 do-release-upgrade 실행했더니 업그레이드 전에 모든 업데이트를 설치하랜다.

https://jimnong.tistory.com/1692

또 구글링 해서 참고해봤다.

~~명령어 입력하고 다시 업그레이드 시도했는데 여전히 같은 상황이었다.~~

사람은 역시 글을 잘 읽어야 한다. 트러블슈팅 내용 남기느라 다시 확인해보니 명령어 입력할 때 버전을 잘못 입력했었다. 다시 입력하니 잘 실행 된다. 드디어 업데이트 시작할건지 물어보는 내용이 나왔다!

당연히 y를 입력해주고 기다린다.

(이미지)
(솔직히 이때 좀 많이 쫄았었다. 기다리니 무사히 넘어가더라...)

사용되지 않는 패키지 제거한다는 내용도 나온다. 마찬가지로 y를 입력해주고 기다린다.

그 뒤로는 알아서 업데이트 해주는걸 한참 기다린다.


(썬더버드 어쩌구 창 이미지)
대충 열려있는 창 닫으라는 것 같으니 닫고 엔터 입력해준다.

또 한참을 기다린다.

Configuration file '/etc/fwupd/fwupd.conf' 설정을 어떻게 할건지 선택하라는 내용이 뜬다.

잘 모르겠으니 현재 버전 유지로 입력했다...

기다렸더니 사용하지 못하게 된 패키지 제거 여부 묻는 내용이 나왔다
수 시간이 걸릴 수 있댄다...

y를 입력하고 또 하염없이 기다린다.

재부팅?

결과 - 24.04 LTS로 잘 업데이트 됐다!!
